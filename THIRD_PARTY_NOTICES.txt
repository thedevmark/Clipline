# Clipline — Third-Party Notices

Clipline downloads and/or bundles the following third-party components. Some are
fetched on demand at runtime into a per-user runtime directory
(LOCALAPPDATA\clipline\runtime on Windows).

## Editor engine (built from a pinned upstream release plus a Clipline patch)

FilmCraft 0.9.0
  Project: https://github.com/storytold/filmcraft
  License: MIT OR Apache-2.0 (LICENSE-MIT, LICENSE-APACHE in the upstream archive)
  Pinned archive and patch: vendor/filmcraft/pin.json,
  vendor/filmcraft/clipline-native-edits.patch

## Desktop UI toolkit (bundled)

Qt for Python (PySide6 / Shiboken6) and Qt
  Project: https://doc.qt.io/qtforpython/
  License: LGPL-3.0

## Media tools (downloaded on demand)

FFmpeg
  Project: https://ffmpeg.org/
  License: https://ffmpeg.org/legal.html
  Windows build source used by this app: https://www.gyan.dev/ffmpeg/builds/

yt-dlp

  License: https://github.com/yt-dlp/yt-dlp#license
